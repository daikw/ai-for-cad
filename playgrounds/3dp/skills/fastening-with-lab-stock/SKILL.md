# fastening-with-lab-stock — 手持ち部品前提の締結設計

3D プリント品（FDM）に、ラボの手持ち汎用部品でねじ止め・磁石固定を設計するためのスキル。
Freedom Level: **中**（推奨パターンを使いつつ、部品形状に応じて調整してよい。ただし在庫表と実測ルールは正本として扱う）。

未実測の値で最終モデルを確定しない。ノギスで実測し、この表を更新してから寸法を確定する。

| INS M3 | 外径 / 長さ | 未実測（この種のセットは外径 ≈4.5mm / 長さ 3〜6mm が典型） | — | — |
| INS M4 | 外径 / 長さ | 未実測 | — | — |
| TAP 各種 | 呼び径 / 長さ / 頭径 | 未実測（M1.4〜M3、皿頭） | — | — |
| MAG-6 | 実径 / 実厚 | φ6×3mm | ノギス未実施 | — |
| MAG-13 | 実径 / 実厚 | φ13×2.4mm | ノギス未実施 | — |
| **MAG-6 ポケット径（H2D Pro / PLA Basic / 0.4mm / 0.20mm層）** | 最適 | 公称 φ6 | **φ6.3**（公称 +0.3。指で押し込めて逆さでも落ちない） | 2026-08-14 |
| **MAG-13 ポケット径（同上）** | 最適 | 公称 φ13 | **φ12.5**（公称 **−0.5**。φ12.5 と φ12.6 に入り、締まりが強い φ12.5 を採用） | 2026-08-17 |

**公称に対する補正量が MAG-6 は +0.3、MAG-13 は −0.5 で符号ごと逆転している。**
FDM の穴縮みだけでは −0.5 は説明できないので、**MAG-13 の磁石実径が公称 φ13 より
小さい（φ12.4 前後）疑いが濃い**。ノギス実測でここを確定させるまで、MAG-13 の
ポケット径を他プリンタ・他材料に外挿しない（φ12.5 はこの磁石ロット固有の値かもしれない）。
φ12.5 は探索レンジの下限に当たっているため、より小さい側は未探索である。

測定環境: Bambu Lab H2D Pro / 0.4mm ノズル / PLA Basic / 0.20mm 層 / 2 walls / 15% infill。
クーポンは `playgrounds/3dp/print-jobs/2026-08-13-fastener-fit-tests/`（HoleProbes.scad 生成）。

**大径薄型（MAG-13 φ13×2.4）は圧入だけで保持しない**。径に対して厚みが薄く側壁のグリップ長が
足りないため、横方向の力で抜けやすい。MAG-13 を使う設計では圧入を当てにせず、
接着 + 段差（座ぐり）か爪で軸方向を受けること。MAG-6 のように「押し込んで終わり」にしない。

この所見は緩い φ13.0〜13.4 で得たもので、φ12.5 での抜けやすさは未評価。締まりが増した分は
改善しているはずだが、厚み 2.4mm というグリップ長の制約は径では変わらないので、方針は据え置く。

## 締結パターンの選択

| 条件 | 使うパターン | 使う在庫 |
|---|---|---|
| 繰り返し着脱するねじ締結（M2〜M6） | ヒートインサート熱圧入 | INS + **小ねじ（在庫ギャップ、下記）** |
| 一度組んだら開けない小径締結（M1.4〜M3） | タッピング直止め | TAP |
| 工具レス着脱・位置保持（蓋・カバー・マウント） | 磁石埋め込み | MAG-6（小物・クリップ） / MAG-13（パネル・蓋） |
| 高荷重で両面にアクセスできる | — 在庫ギャップ（通しボルト＋ナット未保有） | — |

**在庫ギャップ（設計時に必ず告知する）**:
- インサート（INS）に締める**小ねじ（なべ/キャップの machine screw）が在庫にない**。TAP はタッピングねじなのでインサートの相手にしない（ねじ山規格が合わず真鍮メネジを傷める）。インサートを使う設計を出すときは「M3×8 小ねじ要調達」のように必要本数と併せて明示する。
- 通しボルト・六角ナット・ワッシャーも未保有。

## 設計ルール

### 1. ヒートインサート（INS）

- **下穴径** = 実測外径 − 0.3〜0.4mm。**下穴深さ** = インサート長 + 1mm 以上（溶融樹脂の逃げ）。貫通穴にしない
- 下穴は 1〜2° のテーパー（入口広め）にすると自己センタリングして傾き圧入を防げる
- **周囲肉厚** ≥ ねじ呼び径（最低 2mm）。穴周りはインフィルでなくソリッド壁になるようウォールループ数を確認する
- **工具アクセス**: 圧入は上からはんだごてを垂直に沈める。穴の直上に壁・庇があるとやり直しになるので、モデリング時点で真上 60mm 以上のクリアランスを確保する
- ねじ込み深さがインサート長を超える場合（ねじが突き抜けてインサート下端から出る場合）は、下穴の逃げをねじ突出分まで延長する

### 2. タッピング直止め（TAP）

- **下穴径** = 呼び径 × 0.8〜0.85（例: M2 → φ1.6〜1.7、M3 → φ2.4〜2.5）。FDM は穴が小さめに出るので初回はキャリブクーポンで確認
- **ねじ込み深さ** ≥ 呼び径 × 2。積層方向と締結軸が平行だと層間剥離で割れやすいので、可能なら締結軸を積層面に垂直（＝ねじがレイヤーを跨ぐ向き）にする
- 皿頭なので座面には **90° の皿もみ**を入れる。皿径は頭径実測 + 0.4mm
- 着脱は数回まで。繰り返し開ける箇所に使わない（その用途はインサートに切り替え、在庫ギャップの小ねじ調達を提案する）

### 3. 磁石埋め込み（MAG-6 / MAG-13）

- **後入れ接着を既定とする**（印刷一時停止による封入は、磁石のわずかな浮きでノズル衝突するリスクがあるため既定にしない。完全防水・完全隠蔽が要件のときだけ提案し、磁石下に 2〜3 ソリッド層 + 上面シールで設計する）
- **ポケット径** = 磁石実径 + 0.1〜0.2mm を起点にキャリブ。深さ = 磁石厚と同一（フラッシュ）か、磁石を 0.1〜0.2mm 出す。**吸着面側に樹脂を被せない**（0.4mm の樹脂 1 層でも保持力が大きく落ちる）
  - 実測では MAG-6 が φ6.3（公称 +0.3）、MAG-13 が φ12.5（公称 −0.5）。**公称からの補正量は径によって符号ごと変わる**ので、片方の値をもう片方に外挿しない。新しい磁石を使うときは必ず公称をまたぐレンジでクーポンを刷る
- **外壁・エッジからポケットまで** ≥ 1.5mm
- **極性管理**: ペアになる部品は接着前に必ず吸引方向を実物で確認し、磁石にマーカーで印を付けてから瞬間接着剤で固定する。同一プロジェクト内では「外向きの極」を統一しておくと部品追加時に迷わない
- **役割分担**: 磁石は保持のみに使い、位置決めは形状（ピン・リブ・段差）に持たせる。磁石はせん断方向にずれやすいので、せん断荷重は形状で受ける
- 使い分け: MAG-6 はクリップ・小物ホルダー・φ13 が入らない薄物。MAG-13 は蓋・パネル・車載級の保持（複数個配置で保持力を稼ぐ）

## キャリブレーション手順（プリンタ・材料ごとに 1 回）

1. クーポンを 1 枚刷る: MAG-6 / MAG-13 ポケット（クリアランス 0.0 / +0.1 / +0.2mm）、INS M3 下穴（実測外径 −0.3 / −0.4 / −0.5mm）、TAP M2・M3 下穴（0.8d / 0.85d）を並べた 3mm 厚プレート
2. 実部品で嵌合・圧入・ねじ込みを試し、最適値を上の実測表に記録する
3. 以後の設計は実測表の値を正とする。プリンタ・ノズル径・材料が変わったら再取得

## 検証（repo 規約との接続）

- ForgeCAD でモデリングする場合、下穴径・ポケット径・肉厚・工具アクセス空間は checks.forge.js の数値チェックに含める（`--backend occt`）。実測前の寸法は `suite.waived()` で明示
- 磁石ポケットやインサート穴の干渉・肉厚は boundingBox でなく boolean（intersection 体積）で検査する（`playgrounds/forgecad/lib/forge-verify/kernel-pitfalls.md` 参照）
